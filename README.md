# Claude

## Projects

- [**Pokopia Companion Guide**](pokopia-companion/): an unofficial companion app for Pokémon Pokopia on Nintendo Switch 2, for Android, the web, and the ESP32 "Cheap Yellow Display" touchscreen board. It tracks your Pokédex (with pictures of all 1,025 Pokémon), habitats, Ditto's moves, story areas, meals and requests. See its README for how to install the APK.
- [**RG DS multiboot**](rgds-multiboot/): Android + ROCKNIX + Kali Linux on the Anbernic RG DS dual-screen handheld. Builds a microSD card that triple-boots alongside the stock Android, with an OS switcher, a dual-screen/touch setup and gamepad mouse for Kali, and backup and GSI tools for trying newer Android. Not yet tested on hardware; see its README.
