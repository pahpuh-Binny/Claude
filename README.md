# Claude

## Projects

- [**CSI Beacon**](csi-beacon/): firmware for the ESP32 "Cheap Yellow Display" that turns the board into a WiFi Channel-State-Information (CSI) beacon and a standalone WiFi "radar" waterfall display, for WiFi motion/presence sensing. It pairs with a second CSI receiver (such as an M5Stack Cardputer) and has an optional LoRa text link for an attached SX127x module. See its README.
- [**Pokopia Companion Guide**](pokopia-companion/): an unofficial companion app for Pokémon Pokopia on Nintendo Switch 2, for Android, the web, and the ESP32 "Cheap Yellow Display" touchscreen board. It tracks your Pokédex (with pictures of all 1,025 Pokémon), habitats, Ditto's moves, story areas, meals and requests. See its README for how to install the APK.
