# Claude

## Projects

- [**Pokopia Companion Guide**](pokopia-companion/): an unofficial companion app for Pokémon Pokopia on Nintendo Switch 2, for Android and the web. It tracks your Pokédex (with pictures of all 1,025 Pokémon), habitats, Ditto's moves, story areas, meals and requests. See its README for how to install the APK.
- [**Text Editor**](text-editor/): a basic Android text editor that opens any file. JSON, HTML, XML, code and other text open as text; CSV files and Excel workbooks open as a table; binary files open as editable hex. See its README for how to install the APK.
