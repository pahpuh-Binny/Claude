# Claude

## Projects

- [**Pokopia Companion Guide**](pokopia-companion/): an unofficial companion app for Pokémon Pokopia on Nintendo Switch 2, for Android, the web, and the ESP32 "Cheap Yellow Display" touchscreen board. It tracks your Pokédex (with pictures of all 1,025 Pokémon), habitats, Ditto's moves, story areas, meals and requests. See its README for how to install the APK.
- [**Family Frame**](family-frame/): firmware for the ESP32 "Cheap Yellow Display" that makes a digital picture frame with morning, midday and evening news briefings, weather, deals, Marvel news and an optional voice assistant. Family members add photos from their phones by scanning a code on the screen. See its README to flash it and its [wiring guide](family-frame/docs/WIRING.md) for the microphone and speaker.
